JSON Formatter & Validator

Paste JSON to pretty-print it, minify it, or find out exactly what is wrong with it. Everything runs locally — your data never leaves the page.

What this tool does

It parses your JSON with the browser's own JSON.parse and then re-serialises it. That means three things happen at once: the text is validated, it is reformatted with consistent indentation, and any keys you do not need can be dropped by minifying. If the JSON is broken, the browser's parser reports the byte position of the problem, which is usually far more useful than "invalid JSON".

When you would use it

  • Reading an API response. Minified JSON from a server is one long line. Formatting it makes the structure visible.
  • Debugging a config file. Invalid package.json, tsconfig.json or a cloud config usually fails with an unhelpful message — the exact position helps.
  • Shrinking a payload. Minifying strips every byte of whitespace, which can cut a large document substantially.
  • Comparing two files. Sorting keys A–Z makes two documents with the same content but different key order line up identically.

The mistakes this catches

  • Trailing commas — legal in JavaScript object literals, illegal in JSON.
  • Single quotes — JSON requires double quotes around both keys and string values.
  • Unquoted keys — {name: "x"} is JavaScript, not JSON.
  • Comments — // and /* */ are not part of the JSON specification.
  • Invisible characters — smart quotes pasted from a document editor, or a stray byte-order mark.
  • Truncated output — a copy-paste that cut off mid-object.

Privacy

There is no server involved. The text is parsed and re-serialised by JavaScript running in this tab, so nothing is transmitted. That matters when the payload contains tokens, personal data or internal configuration — the kind of content you should not paste into a random online formatter.

FAQ

Is my JSON uploaded anywhere?

No. Parsing and formatting happen entirely in your browser. You can disconnect from the internet after the page loads and the tool keeps working.

What does "Sort keys A–Z" change?

It rebuilds every object with its keys in alphabetical order, recursively. The data is unchanged — only the order of keys. It is useful for making two files diffable.

Can it handle very large files?

Yes, up to the memory your browser tab has. Files above roughly 50 MB may make the tab sluggish, since the whole document has to exist as a string and as an object at the same time.

Does minifying change my data?

No. Minifying only removes whitespace between tokens; every key and value is preserved exactly. The only visible difference is that numbers such as 1.0 become 1, because JSON has a single number type.

Password Generator

Generate a strong password with a real cryptographic source of randomness, and see how long it would take to crack.

What actually makes a password strong

Not symbols, and not "looking random" — the only thing that matters is entropy: how many guesses an attacker needs, on average, to find it. Entropy is measured in bits, and every extra bit doubles the work. Two levers produce it:

  • Length. Each added character multiplies the search space by the size of the character set.
  • Character-set size. Going from 26 lowercase letters to 94 printable characters multiplies each position by 3.6×.

Length wins in practice, because it is linear effort for you and exponential effort for the attacker. A 20-character password drawn from 94 characters carries about 131 bits of entropy. A 4-word passphrase from a 1,000-word list carries about 40 bits — far weaker than it feels, which is why this tool uses a much larger word list and recommends more words.

Why random beats clever

Humans are bad at randomness in predictable ways. We avoid repeating characters, we put capitals at the start, we substitute @ for a and 0 for o, and we append digits at the end. Every one of those habits is encoded in the rule sets that cracking tools apply first — so a "clever" password like P@ssw0rd2026! falls in seconds, while a dull string like k7Qm#vzR2pLw9Xt4 does not.

How this generates randomness

It uses crypto.getRandomValues(), the browser's cryptographically secure generator, not Math.random(). That distinction matters: Math.random() is a fast statistical generator whose internal state can be reconstructed from a handful of outputs, which would make the passwords predictable. The generator here also uses rejection sampling rather than a plain modulo, so every character is equally likely — a naive random() % 94 quietly biases the first few characters of the set.

Passwords vs passphrases

A random 20-character password is the strongest option but is impractical to memorise, so it belongs in a password manager. A passphrase of several random common words is easier to type and remember, and is the better choice for the few passwords you must hold in your head. Note the word random: "correct horse battery staple" is a fine passphrase, but a phrase you invented yourself is likely to appear in a cracking dictionary of song lyrics, quotes and common phrases.

FAQ

Is it safe to generate a password on a web page?

Only if the generation happens locally. This page uses the browser's own crypto API and sends nothing over the network, so it keeps working with the internet disconnected — a quick way to verify any online generator.

Should I use the symbol set?

It adds entropy, but some systems reject or mangle certain symbols. If a site refuses your password, regenerate with symbols off and increase the length by a few characters instead — that recovers the entropy without the compatibility problem.

How long does a password need to be?

For anything that stays in a password manager, 20 characters or more. For something you must type by hand, four to six random words. The limiting factor is almost never the attacker's hardware; it is reuse and phishing.

Is my password stored anywhere?

No. It exists only in the input field on this page until you navigate away.
